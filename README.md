# Корпус сочинений обучающихся русскому языку как иностранному

## Источник текстов

В корпус вошли 73 сочинения студентов, обучающихся русскому языку как иностранному, написанные на одну из тем, данных им преподавателем.

## Разметка текстов

Сочинения были разбиты на абзацы и размечены экспертами. Каждое сочинение размечалось одним экспертом.

Для каждого абзаца было отмечено число орфографических, пунктуационных, морфологических, синтаксических, а также лексических и стилистических ошибок и приведено исправленное написание.

Кроме того, за каждое сочинение в целом были поставлены оценки за сложность текста, соответствие теме, связность текста и уместность его тональности, при этом использовалась шкала от 0 (низкая) до 2 (высокая). Также для текстов размечалась сила их тональности: 0 — тональность отсутствует, 1 — тональность выражена слабо, 2 — тональность выражена сильно. За каждое сочинение была поставлена итоговая оценка по пятибалльной шкале.
